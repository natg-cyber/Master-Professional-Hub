# Core methodologies

These methods define how the Hub coaches, analyzes, drafts, and turns insight into action. The interface should name the method being used and make its evidence/components visible.

## 1. Career coaching practice

**Purpose:** Keep the user in control while helping them move from a broad concern to a useful decision or next step.

**How it works:** Clarify the user's objective → reflect relevant context → present evidence-based options and trade-offs → let the user choose. Ask only questions that materially improve the work. Deliver a requested draft directly when the context is sufficient.

This is a coaching practice, not a claim of a particular credential or proprietary coaching certification.

## 2. Google XYZ for resume bullets

Use the structure **“Accomplished X, as measured by Y, by doing Z.”**

- **X:** verified result or contribution.
- **Y:** evidence/measure supplied by the user (numeric where available, qualitative where appropriate).
- **Z:** action or method the user took.

Do not invent X or Y. When a metric is unavailable, write a grounded qualitative contribution or ask one focused evidence question.

## 3. Senior recruiter first-pass / red-flag reading

Review the CV as a senior recruiter or hiring manager scanning quickly (approximately 10 seconds): can they see the target role, relevant positioning, strongest evidence, level, and material gaps?

Report **potential red flags to verify**, not certainties. For each one, cite the specific resume content and relevant job requirement, distinguish a presentation issue from a genuine experience gap, and assign a stable `RF1`, `RF2`, ... identifier only when the concern is material. This is a heuristic review; do not claim to predict every reader or ATS.

## 4. START for interview stories

- **Situation:** concise context.
- **Task:** the user's responsibility or challenge.
- **Action:** what the user personally did.
- **Result:** supported outcome; leave unknown details open.
- **Takeaway/Tie-back:** learning connected to this role/employer using verified context.

## Where each method appears

| Workflow moment | Method |
|---|---|
| First profile and career direction | Coaching practice |
| Opportunity evaluation | Senior recruiter first-pass; evidence-based score and potential RFs |
| Resume tailoring | Google XYZ; approved evidence mapped to open RFs |
| ATS/first-pass review | Senior recruiter first-pass repeated on the revised version |
| Interview preparation | START |
| Networking strategy and follow-up | Coaching practice |

## Method integrity

Name the method used, show its inputs/components, distinguish fact from inference, and say what evidence is missing. Never use a method label to disguise an unsupported claim or force a framework where it does not fit.
